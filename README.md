# 🎥 resu

**Resumí videos de YouTube con IA y guardá todo en un solo lugar.**

Resu transforma videos de YouTube en resúmenes claros y estructurados para que puedas entender el contenido sin tener que verlo completo.

Podés **generar, editar, organizar y guardar** tus resúmenes desde una misma plataforma.

## ✨ Características

- 🤖 Resúmenes generados con IA.
- 📝 Editor integrado para modificar los resúmenes.
- 📚 Biblioteca para organizar el contenido.
- ⭐ Sistema de favoritos.
- 🔐 Autenticación de usuarios.
- 🎯 Resúmenes estructurados en Markdown.
- 📄 Exportación de resúmenes.

## 🛠️ Tecnologías

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- shadcn/ui
- Strapi 5
- Google Gemini
- Zod

## 🏗️ Arquitectura

```text
Next.js
   │
   ├── Autenticación
   ├── UI / Editor
   ├── Server Actions
   └── Servicios
          │
          ├── YouTube Transcript
          ├── Google Gemini
          └── Strapi 5
```

## 🚀 Objetivo

Resu nació como un proyecto para explorar el desarrollo de una aplicación fullstack moderna y construir una herramienta útil para consumir contenido de forma más rápida.

**Proyecto en desarrollo activo.**
